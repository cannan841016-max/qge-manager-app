# 👑 Q哥店長助理 Pro（iOS 27 液態玻璃版）

專為 **Q哥門市店長** 打造的 iOS 27 個人助理與智慧維修 AI PWA 應用程式，支援直接安裝至 **iPhone 18 Pro Max / 全系列 iPhone 主畫面**。

## ✨ 核心功能
- **🛠️ iOS 維修專用 AI**：內建 `panic-full` / `ResetCounter` 重啟代碼秒速判讀（`prs0`、`TG0B`、`mic1`、`mic2`、`AOP PANIC`、`NAND`、`I2C` 等），涵蓋 **iPhone 8 ~ iPhone 18 Pro Max 與 iPad 全世代 33+ 款機型通病**，並支援**現場隨時新增自訂機型**。
- **📌 門市工作重點紀錄**：早晚班交接、門市業績與促銷、維修與客訴處理、二手機收購盤點四大模板，支援一鍵生成 **LINE 群組交接日報 / 區經理週報**。
- **☑️ 店務待辦追蹤**：急件維修追蹤、進度百分比拉桿、優先級篩選。
- **✨ AI 店長語音幕僚**：內建離線店長智慧引擎，並支援串接 Google Gemini / OpenAI API 與 iOS 語音輸入 / 朗讀。
- **📱 iOS 27 液態玻璃導覽列自訂**：可在「⚙️ 設定」中自由勾選下方導覽列顯示項目、調整順序與自訂名稱。

## 📲 手機隨時修改與自動更新
直接透過 iPhone 上的 **GitHub APP** 或瀏覽器修改 `index.html`、`styles.css` 或 `app.js` 並儲存（Commit），GitHub Pages 即會自動部署，手機重新開啟 APP 即可同步最新畫面！
